Лабораторные работы для курса по автоматическому распознаванию речи ИТМО 2026

# Описание
Всего 7 лабораторных работ. 

Работа считается выполненой в срок, если работающее решение прислано до назначеной даты дедлайна (включая саму дату дедлайна). Главное прислать решение, защитить лабораторную работу можно и после.

Для допуска к экзамену надо прислать лабораторные в срок. Для автомата необходимо сдать все лабораторные в установленные сроки и защитить каждую из них до нового года.
