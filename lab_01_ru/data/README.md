# Данные лабораторной 01

Каталог `wav/` содержит небольшие сгенерированные аудиофайлы без лицензионных ограничений для первой лабораторной по ASR.

Сгенерируйте или обновите их из корня репозитория:

```bash
python updated_course/lab_01_ru/scripts/make_lab_audio.py --out-dir updated_course/lab_01_ru/data/wav
```

Сгенерированные файлы:

- `clean_speech_like.wav` — синтетический speech-like сигнал с voiced-сегментами, fricative-like всплесками и паузами.
- `noisy_speech_like.wav` — чистый сигнал с добавленным фоновым шумом.
- `reverberant_speech_like.wav` — чистый сигнал, свёрнутый с простой импульсной характеристикой помещения.
- `clipped_speech_like.wav` — чистый сигнал, усиленный и клиппированный для демонстрации искажений.
- `speed_perturbed_speech_like.wav` — чистый сигнал с ускоренным временным масштабом.

Эти клипы предназначены для визуального анализа, а не для естественного звучания. Если вместо них вы используете реальные записи речи, делайте их короткими, документируйте источник/лицензию и помещайте в `wav/` с описательными именами файлов.
